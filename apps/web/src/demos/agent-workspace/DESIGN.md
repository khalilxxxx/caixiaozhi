# 财小智 PC 对话 Agent

本入口是面向 PC 的财务对话 Agent，使用模式为 Operate。用户通过自然语言发起查询、办理、分析和配置；应用提供查看、批量处理与精确操作的便捷界面。仅针对笔记本和桌面屏幕设计，不以移动端布局影响桌面信息架构。

视觉采用近白背景、中性灰侧栏、蓝白小智形象与少量珊瑚红主操作，面向企业内部长期使用。文字以中性黑灰为主，浅杏色只用于已选AI上下文；品牌形象出现在侧栏、会话空态和助手身份处。主内容保持克制，不添加功能说明副标题。使用指引位于角落，默认收起。

## 企业品牌与动效

配色参考用户认可的智能提单原型：明亮珊瑚红主操作、白色主体、中性灰文字和少量暖橙辅助。发送图标采用原参考渐变 #ff5b4c → #fa283b；带小号白字的主按钮采用 #db373c → #d9343e，确保文字可读。以美观与角色分工为先，不要求固定使用海康红色值。

页面为 #fafaf9，侧栏为 #f4f4f2，正文 #29292d、次级文字 #525257、辅助文字 #6f6f74。导航选中使用中性灰底与深色文字，只在当前应用图标、标签页细下划线等少量位置点缀珊瑚红。新建会话保持白底深色文字，仅加号使用珊瑚色。已选技能和能力采用浅杏色 #fff3eb 与暖棕文字 #945432；普通能力入口与悬停保持中性。

对话气泡、材料引用、结果卡、历史会话以及规则和技能页面的普通文本、边框统一到中性层。输入焦点使用 #8c8782，不用红色围住整个编辑区域。业务信息蓝、成功绿、警告色、错误色及图表颜色保持独立语义，危险操作沿用明确文案和独立样式。

小智使用现有蓝白原图，不改变角色颜色。新会话问候上方使用64px静态标识，保持输入框本身垂直居中；无消息的草稿会话使用96px淡色小智空态，有消息后隐藏。回复头像与处理中标识统一为32px，普通业务图标继续使用已有线性图标，不重复加角色装饰。

仅处理中的小智图标使用2400ms轻微呼吸与1px位移动效，不延长业务等待，不添加百分比或模拟思考过程。完成与停止后立即移除，页面隐藏时暂停。系统开启减少动态效果时，标识保持静态，会话滚动改为直接定位。首页、空态和已完成回复不循环播放动效。

品牌主题独立保存在 enterprise-theme.css，并在基础样式后加载；修改限定正式Agent入口，保留既有业务逻辑和其他原型样式。

## 会话与应用

新会话首页是主入口。会话承载上下文，业务事项承载办理状态，应用承载直接操作界面。首页不承担 OA 门户或完整任务看板职责。应用与对话使用同一业务对象，切换时保留草稿，选择技能或对象不自动发送。

侧栏宽度272px。新建会话下方直接按顺序展示技能·工具、规则中心、智能提单、全部应用，不设置“常用应用”分隔标题。数据分析、单据进展、制度知识和材料与文件通过可搜索、分类的全部应用到达。后续能力增加不得无限拉长侧栏。接入系统是业务数据来源，不必逐一映射为一级应用。

删除工作空间、我的任务、消息主导航、右上通知、独立搜索按钮和无实际内容的偏好设置入口。待办中心及首页待办区域移除，业务事项仍可在会话内办理。首页无完整顶部导航；应用页面保留标题和必要业务操作。智能提单提供我的单据入口。

## 首页与输入

右侧首页以输入框本身作为三段网格的中间行，在桌面视口中上下相对居中，输入区内容宽约760px。问候放在上方，能力入口和随机示例放在下方；不把所有内容整体居中而使输入框偏上。输入框内保留上传文件、选择技能。文件和业务引用留在输入材料区，可移除。

技能从底部入口打开可搜索的小浮层，复用技能·工具的权限与版本状态，支持即时多选。选中后状态保留在原入口：单项显示技能名称，多项显示数量；点击再次选择，可在列表逐项取消或从底部清除。技能不再作为顶部附件式标签。浮层向上打开，列表高度随视口限制并内部滚动；Escape关闭并回焦点，外部点击和焦点离开关闭。技能选择只更新当前草稿，不新建空会话、不发送、不覆盖文字与附件。

首页采用 B 版能力直达形式。输入框下展示智能提单、规则配置、数据分析、单据查询、制度问答与更多能力。入口从侧栏及全部应用提炼为任务名称；更多能力收纳材料整理、回单查询、附件翻译、合同分析，避免能力增长拉长首页。技能·工具沿用底部技能入口，不复制为同义首页选项。

点击能力只切换当前处理上下文、输入提示及示例，不插入长提示词、不发送、不打开业务应用。选中状态位于输入框底部，可从锚定浮层搜索切换，或用关闭按钮退出；默认能力入口行此时收起。切换和退出均保留文字、文件及已选技能。已有会话的输入框仍位于底部，提供同样的能力切换入口。

能力作为独立字段随草稿和会话保存，发送时进入对应业务分支，避免仅靠关键词错分任务。从单据或制度详情发起明确追问时，以该详情的业务上下文为准；普通附带引用不自动覆盖用户选择的能力。未接入实际服务的功能在发出请求后如实说明，不能借用报销或费用分析示例返回假结果。

能力入口下展示3条随机示例问题，选择能力后展示该能力的示例，并提供换一组。示例在用户输入时保持稳定，无自动轮播；选择后仅准备可编辑草稿。示例是用户明确要求的能力引导，文案保持真实业务语气，不增加教学段落。

首页输入框下仅保留能力入口和示例问题，不显示待办提醒、进行中列表、应用卡片或统计看板。办理进度通过会话记录和对话中的业务卡片查看。

## 最近会话

标题、最后一条消息的相对时间、执行状态图标共同组成38px高的单行会话项。标题超长时截断，时间和状态不换行，默认不显示中文状态。图标使用现有线性图标系统，提供悬停说明与无障碍标签；执行中、待我处理、异常、完成和外部等待分别表达，不仅靠颜色区分。完成图标指本次 Agent 执行结束，不代表审批通过或付款成功。

时间来自最后一条消息的时间戳。后台业务刷新不改变消息时间。旧记录无法确认绝对时间时不显示虚构的相对时间；已有固定示例消息可以迁移已知日期。会话按消息时间排序，未知时间保持稳定顺序。会话列表占据侧栏剩余空间并独立滚动，应用入口与底部个人信息保持可达。最近会话标题悬停或键盘聚焦时，右侧出现“全部对话”；在历史页面时保持入口可见。

## 全部对话

独立历史页面使用 #history 路由，页面标题为“全部对话”。支持搜索会话标题、各条消息正文及未发送草稿，保留原消息时间排序；展示摘要、时间和图标状态，点击恢复同一会话。空历史与搜索无结果分别提示，不修改或清空记录。⌘ / Ctrl + K 进入此页面，不再打开全局搜索面板。离开首页时通过既有草稿保存机制保留未发送内容。旧待办路由安全回落首页。

## 弹层形式

交互容器按任务选择，采用项目根目录 DESIGN.md 中“居中弹窗与右侧抽屉的选型”约定。

- 智能填单（界面入口目前名为“智能提单”）相关的填写、补充修改、校验与提交操作整体使用右侧抽屉，按内容量在抽屉内组织完整流程，保留会话上下文与草稿。此场景约定优先于完整表单采用居中弹窗、复杂编辑采用独立页面的一般选型规则。
- 上传技能使用空间充足的居中弹窗，按现有业务字段组织基本信息、用途与适用范围、文件信息和校验反馈，便于集中填写与检查。
- 从当前会话查看单据、进度、证据或技能详情，以及依赖原消息的少量修改，优先采用右侧抽屉。需要边查看边继续会话时，采用允许背景操作的侧栏面板，保留草稿与滚动位置。
- 弹层的居中或侧置布局与模态行为分别评估。使用遮罩和焦点锁定的容器会暂时阻断背景操作，关闭后焦点回到触发控件。
- 输入框内选择技能沿用锚定入口的小浮层。复杂的持续编辑按内容量评估独立页面或全屏工作区。

## 验证与边界

关键文字对比度至少4.5:1，控件具有可见焦点和准确名称。菜单支持 Escape 与外部点击关闭，选择后焦点回输入。重点验证1440×900与1280×800，应用列表增长、长会话标题、草稿保留、技能权限、连续引用和随机示例不扰动输入。

现有集中处理台对照入口保留，不增加新的模式选择入口。前端原型使用既有数据与办理逻辑；真实服务接入能力和限制写入交付记录，产品中保留必要业务状态。

## 智能提单业务字段

2026-11-16 按确认后的业务字段提供差旅申请、差旅报销、个人费用报销三个入口。基本信息使用当前申请人、授权部门、付款公司和单据事由，差旅类型为普通差旅或短期异地办公。

差旅申请使用多段行程，每段保存出发城市、到达城市、出发日期、到达日期、交通工具及席别。行程支持增删和排序，提交检查包含衔接、日期、首尾闭环和中途返回起点条件。活动／派工按用户配置显示，使用原字段“比例／工时”，同行人分别形成提交请求。

差旅报销关联申请及实际行程。个人费用使用市内交通、业务招待、其他一级目录，其他目录保留已核实的长途交通、住宿费细类。报销费用依实际模板显示日期或期间、行程或用餐OA关联、币种、金额、事由及住宿、接待专属字段。费用事由使用其他选项和自定义文本，发票、费用补充附件、单据附件各自关联。

AI首次默认币种CNY及适用的非租房，其他字段使用返回值或保留待补状态。改类型按当前值迁移，保护人工填写及清空。住宿退房日期改写使用待核对提醒，完整性和原业务规则决定提交资格。

材料按差旅、个人费用进入对应草稿，逐笔用途、OA、文件及实际期间贯穿保存。旧草稿保留已有金额、原期间及文件关联，新增必填项可继续补充。修改字段或规则后，先前检查随版本失效。

当前组织和交通目录沿用演示上下文，外部申请、OA、城市映射、跨单重叠校验、OCR、发票查验和正式提交等待业务接口。上传保存文件元数据，当次会话可打开本地原件，刷新后的二进制原件需由文件服务提供。活动交集当前按包含日期端点、逐项有交集处理。

## 智能提单对话与办理

对话使用紧凑单据卡：类型和状态、事由、行程或费用金额、待完善项及两个操作。最新卡片读取当前草稿，历史卡片收起为只读快照，不再随新草稿重写。打开卡片后，在右侧抽屉的“单据概览／编辑单据”之间切换，完整业务字段沿用实际模板；保存、检查、核对提交和回执均在同一容器中。

宽度至少1280px的会话使用允许背景操作的右侧栏，较窄视口与应用入口使用右侧模态抽屉。主单修改及时暂存；未确认的费用子表按单据单独暂存，关闭后恢复，保存或取消费用前禁止整单检查与提交。正式草稿、未保存编辑、历史卡片、提交快照分别保留，修改后旧检查不再允许提交。

当前自然语言处理仅提供明确语句的本地映射，用于评审增量填写交互。没有明确的到达日期、交通席别等继续保留待补状态，不编造OCR识别、业务回执或审批成功。演示输入说明放在默认收起的使用指引中。

## 技能与小工具

“技能·工具”沿用 `#skills` 路由，包含技能目录、小工具、我的技能和团队资产。原有技能引用及治理流程保留。小工具通过同源页面嵌入，入口为 `#skills?tab=tools`，工具分享链接为 `#skills?tab=tools&tool=工具ID`。小工具不重复显示 Agent 侧栏和页面标题，返回技能目录在同一工作空间完成。当前小工具的模拟身份与权限状态独立，尚未与 Agent 对话及服务端权限统一。


## SRS 规则中心前端演示

2026-11-16 按 SRS 的规则台账、业务逻辑、适用条件、证据要求、输出粒度与版本结构迁移当前规则中心。沿用当前企业主题和 `#rules` 入口，不复制独立 SRS 后台的导航及教学副标题。

规则台账提供公司／个人／草稿视图、名称与逻辑搜索、分类、风险和启停筛选。详情使用右侧抽屉，包含规则逻辑、适用条件、证据字段、变更记录。完整编辑位于规则页面，左侧编辑业务逻辑，右侧展示只读解析；所有角色都没有字段、字典、证据映射或输出模式的配置控件。

默认保留当前七条示例规则。引用示例收起，提供住宿每间夜提醒、每单餐饮合计提醒、发票重复提醒。生成仅支持受控示例句式及数字调整；不支持的条件明确返回错误，不静默丢弃。生成后改文字使解析过期，不能直接保存启用。草稿与现行版本分离，保存新版本前核对差异，停用不改变内容版本。

本轮为本地前端演示。固定财务身份可演示公司规则维护，未接正式授权；个人规则仍只能提醒本人。页面使用简短“示例数据 · 本地保存”标识，详细范围说明放在角落的使用指引。规则保存在现有工作空间的 `srsRuleCenterV1` slice，生效规则投影到旧前端预审模型，保留旧检查结果及版本失效提示；不接后台、不调用真实大模型，不实现正式发布或服务器测试。

预审设置移入批量待审单据底部操作区。只读规则可继续加入对话，从审单查看规则后可返回原单据。浏览器验证覆盖1440×900、1280×800，以及草稿恢复、版本保存、历史、失效、错误与启停。
