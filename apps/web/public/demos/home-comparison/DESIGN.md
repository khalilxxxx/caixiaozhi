# 财小智首页双方案

Operate：两版首页延续现有PC蓝白财务Agent视觉；报告index.html为Read。当前正式agent.html不修改。

统一：272px浅灰侧栏、760px输入区、蓝色#326be2、主文字#27344a、背景#f9fafc、现有机器人品牌。应用固定四项，最近会话单行。只针对PC，不开发移动版。

A：场景分组与输入框上方任务入口，通过相关指令样板准备草稿。B：输入框下方能力入口，选择后切换专属输入提示、底部能力状态和示例。两版输入框视觉中心接近主区中线。

功能选择不发送、不覆盖原文字或材料；技能选中留底部，附件位于材料区。浮层锚定入口、可搜索、支持Escape和外部关闭。使用指引默认收起。发送明确只做本地预览，不模拟成功业务回执。文件不上传，不引入网络请求。

原型内不常驻设计说明，研究、版本边界和适配结论集中在对照报告。两版本地HTML自包含，index中截图及关联页面为同目录资源。验证目标为1440×900、1280×800、长文字、场景/能力切换保留、技能多选、无结果、键盘与发送反馈。
