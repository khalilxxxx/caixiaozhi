# 工具中心界面与实现约定

本页面是财小智蓝白工作空间下的 Operate 页面，沿用现有机器人品牌、海军蓝文字与浅色办公背景。源码以 `apps/web/public/demos/tool-center/` 为准，主入口为本地 5190 的 `agent.html#skills?tab=tools`，以同源嵌入方式整合到 Agent 的“技能·工具”页面。独立入口继续保留。

## 已批准的范围

工具中心、两表核对、台账转换、费用分析报告、上传与双审发布、可见和使用权限、对话入口。Skill 与小工具是不同资产：工具直接打开使用，Skill 用于 Agent 方法复用。第一期不实现在线 AI 编程平台，不部署自定义后台代码，不调用真实业务系统。

## 视觉与布局

- 主色 `#3667df`，深色文字 `#1c2d49`，次要文字 `#65738b`，背景 `#f6f8fc`，分隔线 `#e3e8f0`。
- 侧栏 228px（中屏 204px），主内容边距 35px，标题 25px，正文 14px。办公页面采用系统中文无衬线字体；金额用等宽数字。
- 目录桌面三列，工具名称与图标同一行，卡片只保留用途、类型、维护人、版本和必要操作。管理与记录使用紧凑表格。
- 工具独立页面容纳字段映射和宽表格；结果与异常同页查看。960px 以下适当折列，600px 以下导航缩为图标、工具列表单列，横向表格局部滚动。
- 上传为较宽的居中弹窗；详情、权限和双审为右侧抽屉。使用原生 dialog 保持焦点与 Escape 行为，关闭返回触发元素。上传未保存字段在当前页面会话中保留。
- 角落“使用指引”默认收起。没有页面用途副标题、体验路线或自动弹出的教程。保留真实错误、数据来源和 AI 未接入状态。

## Agent 内嵌模式

内嵌模式隐藏独立侧栏、品牌区和重复目录标题，复用 Agent 外层导航。工具区保留目录、我创建的、审核管理，以及演示身份和默认收起的使用指引。工具详情、上传和审核保持原有交互。技能链接通过校验来源的消息返回原生技能目录，分享链接指向 5190 同一工作空间。独立工具对话入口在嵌入模式隐藏。

## 代码分工

- `app.js`：导航、目录、对话、详情、身份、访问申请、共享面板容器。
- `model.js`：初始数据及可见/使用权限。
- `tools.js` / `finance-core.js`：工具界面与纯计算。
- `manage.js`：上传、双审、发布、版本与分享。
- CSS 与对应模块分开；不用远程字体、外部 CDN 或额外运行依赖。

## 验证限制

已做源码与 Node 逻辑验证，尚无浏览器截图验收。不能把原型前端授权、CSP、示例审核或基础报告描述成正式服务能力。
