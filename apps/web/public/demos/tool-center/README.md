# 财小智工具中心 · 本地交互原型

本原型用于业务与开发的初步需求评审，延续 Skills Hub 的资产管理思路，增加可直接打开使用的财务小工具。所有代码均在本机项目内，无云端发布、远程存储或大模型调用。

## 本地入口

- 财小智首页：http://127.0.0.1:5190/agent.html#home
- 技能·工具 → 小工具：http://127.0.0.1:5190/agent.html#skills?tab=tools
- 两表核对：http://127.0.0.1:5190/agent.html#skills?tab=tools&tool=reconcile
- 台账模板转换：http://127.0.0.1:5190/agent.html#skills?tab=tools&tool=convert
- 费用分析报告：http://127.0.0.1:5190/agent.html#skills?tab=tools&tool=report

已整合进 5190 的 Agent 工作空间。侧栏与页面标题统一为“技能·工具”，页面包含“技能目录 / 小工具 / 我的技能 / 团队资产”。小工具页内可进入“工具目录 / 我创建的 / 审核管理”。上传、使用、权限和分享均在此工作空间内操作；分享链接回到同一工作空间对应工具。

如本机服务已关闭，在项目根目录执行 `node apps/web/node_modules/vite/bin/vite.js --config apps/web/vite.agent.config.ts`。分享链接是 localhost 地址，无法让其他电脑直接访问。

独立原型仍位于 `/demos/tool-center/index.html`，原 Skills Hub 首页已跳转到该独立页面，旧首页保留为 `index-v1.html`。5173 和 5190 是不同浏览器来源，已有演示数据不会跨端口自动迁移。

## 已实现

1. 工具目录、搜索、分类、收藏、详情与关联 Skills；嵌入模式返回原生技能目录，旧版独立 Demo 保留。
2. 两表核对：读取两份 CSV，选择关联字段和金额字段，输出匹配一致、金额差异、单边记录、重复待确认、数据异常，并导出结果。
3. 台账转换：字段映射、日期和金额及必填校验、异常记录定位；只导出校验通过的记录。
4. 费用报告：实际计算部门与费用类别汇总、净额与冲减，查看明细并导出 HTML 基础报告。AI 解读和 Skill 执行没有接入，界面明确标识。
5. 上传 HTML、保存草稿、隔离预览、业务与技术双审、管理员发布、分享授权、停用恢复和新版本。新版本发布前保留正式版本；驳回锁定，修订须提高版本号。
6. 独立原型保留对话中的工具选择、关键词匹配、概要入口与本人最近结果。5190 工作空间使用原有 Agent 对话；本轮仅整合应用页，未把独立原型的工具对话接入 Agent。
7. 员工申请使用、管理员处理；直接链接也校验当前模拟身份。可见与使用分别控制，分享链接不授予权限。

## 评审路径

- 先用林晓打开三个工具，默认有标记明确的示例数据，可替换自己的 UTF-8 CSV。
- 通过小工具顶部“演示身份”切换王晨：台账转换可用，另外两个工具需申请。许宁在目录“访问申请”中处理。
- 林晓上传 HTML（可选择“使用示例文件”），提交审核；周敏审核业务，陈屿审核技术，许宁发布。正式工具出现在工具中心。
- 对已发布工具上传新版本，核对审核期间正式版本保持可用；任一审核退回后提交修订，不能直接改写审核结论。
- 上传是较宽的居中弹窗；详情与审核是右侧抽屉。页面右上角“使用指引”默认关闭。

## 数据与能力边界

- 内置工具支持 UTF-8 CSV，单文件最大 2 MB、最多 5,000 条数据；不解析 XLSX。金额使用整数分，拒绝无效精度或超过安全范围的值。
- 内置工具的业务文件仅保存在当前页面内存中，按模拟用户隔离，刷新后消失。业务文件内容不会写入 localStorage，也不上传服务器。
- 工具定义、上传的 HTML 源码、审核、权限、收藏、申请及概要记录保存在此浏览器 localStorage。用户主动点击“重置演示数据”可恢复初始状态。
- 所有人名、部门、初始工具和既有审核记录均为合成示例。身份切换、审核、发布及权限全部是前端原型，不能充当正式服务端鉴权。
- 上传 HTML 限制 200 KB，使用 iframe `sandbox="allow-scripts"` 与限制外部资源的 CSP。此措施用于原型隔离展示，不构成生产网络隔离保证；自导航等行为仍需服务端审查与运行策略，不能直接承载不可信代码。界面不会声称自动安全扫描通过。
- 纯前端源码会下发浏览器，取消下载入口不能保证源码保密。工具与数据的共享权限应分别治理。
- 内置工具替换成上传 HTML 的新版本后，会按自定义工具运行；内置处理功能不会继续冒充新版本。
- 两表核对采用明确键值及金额匹配，重复键逐行保留为待确认，不做自动模糊通过。报告只生成确定性汇总摘要，不编造预算、同比或因果结论。
- 嵌入模式的技能链接返回原生技能目录；小工具仍使用自己的模拟身份及本地权限状态，尚未与 Agent 共用身份、服务端权限和运行记录。
