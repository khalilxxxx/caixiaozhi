# 三版对话交互预览

用户要求先分别体验三版，再决定正式方案。此目录为独立本地原型，未改动正式 Agent 的界面、数据或后端。

入口：`http://127.0.0.1:5190/demos/conversation-comparison/index.html`。

- A 专业有温度：开放式工作清单，当前动作与任务编排可见。
- B 有陪伴感：较明显的小智形象、自然动作回应、轻量阶段轨迹。
- C 极简高效：当前动作单行，记录按需展开，结果优先。

切换方案保留阶段、选择、输入草稿与展开状态；可重播、暂停预览、跳转阶段、回答追问、停止续办、异常重试、展开记录、查看报告和复制。等待问题不自动选择。页面隐藏时暂停本地播放；减少动效时保留静态状态。

预览工具栏与底栏属于方案比较环境，内层按真实产品呈现；使用指引默认收起。整个过程由显式本地示例状态驱动，展示的材料、金额、执行与耗时不代表实际业务运行。两种归集口径使用不同且加总一致的示例金额。不上传文件、不调用模型、不发送普通消息、不办理任何真实财务动作。
