能力中心与轻应用

财小智主界面采用两个入口。用户在“能力中心”查找专家团、技能和连接器，在“轻应用”打开计算器或上传自己的 HTML 应用。主界面可打开对应原型。

两个入口分别办理什么事？

入口用户操作交付结果
能力中心在同一目录搜索，或按专家团、技能、连接器筛选。用户可向专家团描述任务，也可直接打开单项技能或查看连接器权限。核验发现、可回查的依据、实际使用的技能与连接器，以及受限事项。
轻应用在新标签页打开费用分摊计算器，输入总额与部门权重。个人应用可从本机上传。分摊到分的费用明细。上传成功的应用可从本浏览器的“我的应用”再次打开。

专家团适合一次请求包含多项核验的场景。用户已知要做的检查时，可以直接从目录打开单项技能。要了解数据是否可用时，可以查看连接器的当前身份、业务范围和权限。

财务核验专家团如何选择能力？

“财务核验专家团”面向用户呈现为一个智能体。任务交给它后，它会在材料完整性检查、差旅标准核对、供应商主体核验三项技能中选择本次所需的能力，再按当前身份读取报销单据、差旅制度库和企查查中的相应数据。用户只需说明核验目标并提供业务对象。

用户的任务实际使用结果
只核对住宿标准差旅标准核对，读取报销单据和差旅制度库。北京示例单每晚 580 元，2 晚合计高于每晚 500 元的标准 160 元。可查看住宿发票与示例制度。
预审整张报销单材料完整性检查和差旅标准核对，共用同一份报销单据，并读取差旅制度库。逐项列出材料和住宿的核对结果。北京示例单还缺网约车电子行程单。
核对附件和供应商主体材料完整性检查读取报销单据。供应商主体核验按身份使用企查查。员工得到附件核对结果，供应商查询标为受限。财务复核员可同时得到所选供应商的登记名称和经营状态。

结果记录实际用过的技能和数据来源。缺少核验对象时提示补充，受到权限限制时说明原因，其余具备条件的检查可以继续。当前原型用本地规则选择任务分支，用合成单据、制度、供应商快照和示例身份演示核验过程。

与腾讯 WorkBuddy 的“专家团”有何不同？

腾讯官方文档将专家、技能和连接器放在同一管理入口。专家按任务选配技能与外部服务，技能市场支持安装、上传和创建，连接器可以预先授权或在执行时连接。官方“报销单合规预审”案例将材料核对、制度比对和证据列示组合为一项技能。

腾讯的专家团由团长拆解任务，交给多个专家并行处理，最后整合交付。财小智沿用统一目录和按任务调用能力的思路，以一个智能体组合多项技能与数据连接。这里的“团”指同一财务核验入口具备的能力组合，原型中的实际执行单元是被选中的核验规则。

目前能上传什么，正式接入还需要什么？

个人轻应用。作者填写应用名称和版本，选择单个自包含 HTML 文件。完成文件校验后，应用保存到本机浏览器，重新打开时在独立标签页的隔离区域运行。清除该站点的浏览器数据会移除已保存的应用。

企业数据连接。原型中的企查查结果来自合成快照。正式接入仍需配置企业 MCP 服务、组织授权和服务端逐次判权，区分无权限、资料缺失和服务故障，并记录实际调用。

组织分发。面向同事共享需要云端托管、作者和版本记录、审核、可见范围校验及撤回机制。这些属于正式发布链路。当前的“保存到本地”仅在当前浏览器的相应演示身份下生效。
