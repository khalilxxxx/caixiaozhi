catalog.html      技能中心：搜索、筛选、详情、收藏、下载与权限申请。

直接用桌面浏览器打开 HTML 即可，无需安装或启动服务。
页面自身没有网络依赖。只有分析文档中的外部来源链接需要联网。

推荐体验
1. 在技能中心对比“月度费用分析”和“英文报告风格”。
2. 切换普通员工/财务分析员，查看可见与调用范围的变化。
3. 在审核工作台切换业务审核员/技术审核员，完成双审与发布。
4. 体验退回锁定、作者提交修订、同名同版本拦截和权限扩张待审。
5. 打开对话页面，选择月度费用分析，补充月份与部门后运行。
6. 切换缺权限、停用和失败场景，导出示例报告。
