# 财小智用户场景测试用例

**V1 · 待确认 · 30 条**

本轮从员工、审批人、财务分析人员和能力维护人员的日常任务出发，验证他们能否找到入口、理解下一步、完成办理、核实结果，并在中断或出错后继续。测试时同时记录影响效率或判断的操作，即使任务最终完成，也可以提出体验优化。

范围采用当前工作区的 [财小智 Agno 工作台](http://127.0.0.1:5190/agent.html#home)，包含工作台内的轻应用。旧版 5173 工程与独立对照样板单列为后续范围。员工、审批人等是场景角色，本地版本以合成数据和当前演示身份验证业务行为。真实 OA、报销、付款、企业查询以及多用户隔离的验收需要相应接入环境。相关约定见 [产品约束](../PRODUCT.md)、[界面约定](../DESIGN.md) 和 [本地入口说明](../README.md)。

| A02 | 办理时间长，先做另一件事，回来接着处理 | 发送 A01 或 D01 的查询，出现运行状态后切换到另一会话 → 回原会话并刷新 → 查看「执行记录」 | 消息、产出及运行状态留在正确会话。可确认当前是否完成，连接恢复后仍能查看同一任务。刷新或切换没有重复发送或把结果写入另一会话。 | 高 |
| A03 | 发现发错了任务，停止后补充需求 | 在真实任务仍运行时点「停止办理」→ 查看状态 → 使用「继续处理」或在原会话改问明确需求 → 核对最终输出 | 真实显示停止或已完成的时序。停止后的旧任务不再追加为成功，原消息保留。重新处理有独立的过程和结果。若任务已结束，重开一条较长的只读任务再验证停止。 | 高 |
| A04 | 系统问我要补什么，我暂时没有答案 | 输入「帮我申请从杭州出差去上海拜访客户，去程日期还没定，返程也不确定」→ 出现追问后先暂不处理或切走 → 返回原会话补上去程和返程时间 → 打开对应草稿 | 追问说清缺项和下一步。回到原会话仍可回答，地点和事由保留，补充内容落到同一草稿。重复打开旧追问不会产生第二份草稿或覆写后续回答。 | 高 |
| A05 | 第二天需要找到昨天的结论和新结果 | 给两个会话使用易区分的主题，离开其中一条等待后台结果 → 从「最近会话 → 全部」搜索并重命名 → 使用「消息中心」筛未读、打开目标、标已读 → 在同一浏览器刷新 | 搜索和重命名可找回原聊天及成果。新通知指向对应会话，已读状态在同一浏览器刷新后保持。待回答、办理异常、自动化结果出现时有可辨别状态。 | 中 |

| B03 | 出差后要用已审批的申请做差旅报销 | 新建差旅报销 → 在「关联差旅申请单号」搜上海 → 选已审批的 `TA-20261113-015`「上海客户验收」→ 核对回填行程 → 填 2026 年 11 月 17 日客户停车费 45.30 元并补对应合成原件 → 切另一份草稿再返回，检查并确认提交 | 未审批的 `TA-20261116-023` 不可选。已选申请和实际杭州往返上海行程关联正确，停车费及原件留在对应草稿，报销合计可逐项复算。办理后能从报销单追溯对应申请。 | 高 |

| B05 | 同一张票误传两次，另有一张读不清 | 上传同一原件的副本与无法辨认的合成票据 → 查看重复、识别失败或待核对的信息 → 去掉重复项，补传清晰件或手工录入 → 核对已保存费用 | 重复票可辨别且不会重复计费。无法读取的金额或日期留待补录，用户知道该换文件还是手工补齐。失败不覆盖已确认值。 | 高 |

| B08 | 收到外文材料，要把译文和原件对上 | 在会话选择「附件翻译」，上传含英文费用名、金额和日期的合成 PDF → 点「开始翻译」→ 点击译文定位原件文字，再点原件对应标注 → 从材料与文件下载原件并重新打开翻译 | 原件下载内容与上传一致，中文译文对应所选材料和原文位置，金额与日期可逐项比对。刷新后可从已保存结果复查。无法解析或模型失败时能看到原因及恢复入口。 | 中 |

## 执行环境与证据
