# 通用技能本机运行说明

当前交付面向本机单用户 Demo。复用现有 Agno 对话、SQLite 与文件存储，增加通用技能包读取、任务工作区、受限脚本执行和成果交付。公司服务器的多用户身份、数据授权及部署隔离仍需按服务器环境另外接入。

## 使用

1. 在“技能·工具”添加 `.md/.txt/.json/.yaml/.yml` UTF-8 指令文件，或含 `SKILL.md` 的 `.zip` 包。ZIP 可在根目录放置 SKILL.md，也可包含一层包目录；保留 scripts、references、assets 及其他资源。上传入口当前最大10MB；ZIP 解压后最多500个文件、单文件10MiB、总计50MiB，拒绝越界路径、链接和重复路径。
2. 查看真实包检查及缺失依赖；填写名称、用途和版本后保存。按既有流程申请业务和技术审核，通过后上架可调用版本。无依赖或结构问题不等于已完成业务质量审核。
3. 在对话选择技能和需要处理的材料，描述输出要求。也可要求 Agent 查找适用的已上架技能。Agent 按需加载指令和资源、写工作文件、执行脚本、发布成果。
4. 从成果卡打开预览或下载。继续修改时，Agent 可将同会话既有成果作为新任务输入；原成果保留。

## 当前运行能力

- Python：python-pptx、openpyxl、pandas、matplotlib、Pillow、reportlab、python-docx、pypdf 等依赖由服务虚拟环境提供，版本由 uv.lock 锁定。
- Node：使用本机 Node；预装 `pptxgenjs`、`exceljs`，由 `apps/agno-service/skill-node/package-lock.json` 管理。支持 `.js`、`.mjs`、`.cjs`，通过只读受控模块目录加载依赖。依赖是否实际就绪以技能检查与执行器反馈为准。
- 支持包内 `scripts/` 目录及任务 `work/` 目录中的 `.py/.js/.mjs/.cjs/.sh` 脚本；运行前必须加载已发布的上传技能。不会执行上传包中的安装命令，不自动从网络安装依赖。
- 包检查读取 `requirements.txt` 与 `package.json` 的 `dependencies`，核对本机已安装版本。Python 支持常规包名、版本约束和环境标记；外部来源、额外依赖组及安装选项不自动解析安装。Node 当前检查精确版本、`^`、`~`、`*` 等常见版本声明；未支持的声明不会被当成已满足。仅含说明和资源的包可在依赖警告下继续读取；带脚本且依赖未满足的包暂停调用。检查通过仍不保证所有运行时需求均已满足。
- 输入只复制当前引用的文件。每轮独立工作目录，input 与 skills 只读，work、output、tmp 可写。技能文档中的相对路径需要按加载结果的 basePath 解析。
- 当前 macOS 使用 sandbox-exec，限制文件访问并禁止网络，子进程不继承模型密钥和服务环境。若平台不具备受控执行条件，明确关闭脚本执行，不降级为裸执行。
- 脚本支持 `.py`、`.js`、`.mjs`、`.cjs`、`.sh`，入口须位于 `skills/<包名>/scripts/` 或 `work/`。为保证整组清理，禁止 `setsid`、`setpgid` 和 `posix_spawn`；依赖这些调用的子进程库可能不可用。Python 默认 `subprocess` 和本机 Office 转换已验证可用。
- 每个脚本默认60秒、最多120秒；每路日志保留前128KiB，单文件最多64MiB。执行期间监测整个进程组的1GiB驻留内存、32个进程及工作区100MiB/1000条目上限，另限制CPU时间和打开文件数。内存、进程数与工作区总量采用周期检查，可能在发现超限前短暂超过阈值；超过限制会停止执行。
- 正常退出、取消、超时和服务正常关闭会清理执行进程组。服务被强制终止（如 `SIGKILL`）或崩溃时，父进程的监控会中断，子进程可能作为孤儿继续运行；当前没有独立监督器保障这种异常情况的清理。不得将重启后显示“暂停”视为所有孤儿进程均已停止。不宣称具备公司服务器的多用户安全隔离。
- 单个成果最多25MiB，每轮最多30个成果。生成文件存入独立成果记录，不依赖临时工作目录。HTML 预览使用沙箱 iframe 和严格 CSP；Office 预览通过本机 LibreOffice 转为 PDF。执行器从本机 `PATH` 解析 `soffice`、`pdftoppm`，对已发现的 Codex runtime 依赖目录授予只读访问，并设置该 LibreOffice 自带的字体配置；这些二进制不由 `uv.lock` 或 Node 锁文件安装。缺少工具或隔离不兼容时可能无法预览，原件仍可下载。
- 对话最多24次工具调用、整体最多600秒；单个脚本最多120秒。服务重启保留会话、事件、上传和成果，将未完成运行标为暂停，不宣称能从任意代码中断点自动续跑。

## 样例与检查

两个普通技能包的源码位于 `examples/skills/office-presentation` 和 `examples/skills/table-report`，不依赖专用业务接口，也不冒充第三方 ppt-master。

```sh
python3 scripts/build-example-skills.py
apps/agno-service/.venv/bin/python scripts/test-example-skills.py
apps/agno-service/.venv/bin/python scripts/test-general-skills-live.py ppt
apps/agno-service/.venv/bin/python scripts/test-general-skills-live.py xlsx
apps/agno-service/.venv/bin/python scripts/test-general-skills-live.py ppt-edit
node scripts/test-general-skills-browser.mjs
```

打包输出在 `artifacts/general-skills-20261117/examples/`。真实模型验收脚本会在当前本机工作空间安装两个已验证的样例技能、创建验收会话并生成文件；其他技能、会话及业务数据保留。

## 接入其他技能

需要读取实际技能包才能确认兼容性。技能只写指导内容时，可依赖当前通用工具创建脚本；带脚本时可直接调用包内脚本。要求专用平台工具、未安装的第三方依赖、任意网络、浏览器交互或其他操作系统能力的技能，需要补充受控适配后再启用。名称相同不代表工具接口相同。

迁移到 Linux/Windows 公司服务器时，应替换执行器适配层，保留技能包、工作区、执行记录和成果接口；必须先补齐用户归属和下载/任务/业务授权，不能把本机目录隔离视为多人生产部署完成。
