# 财小智 Agno 本地 Demo

## 入口与启动

访问 **http://127.0.0.1:5190/agent.html#home**。

在项目根目录运行：

```sh
pnpm demo:agent
pnpm status:demo:agent
pnpm stop:demo:agent
```

也可双击 `scripts/demos/start-agent-workspace.command`，启动并打开浏览器。脚本会检查已有服务、复用可用的5190入口，并仅停止本启动器登记的进程。服务在后台运行，关闭启动终端不丢失业务数据；电脑重启后重新执行启动命令。

首次在其他机器安装：

```sh
pnpm install --frozen-lockfile
uv sync --project apps/agno-service --python 3.12 --frozen
npm ci --prefix apps/agno-service/skill-node --ignore-scripts --no-audit --no-fund
cp -n .env.example .env
pnpm demo:agent
```

本地产品使用 Python 3.12、Agno 3.2.0、FastAPI、SQLite 和现有 React/Vite。依赖版本由 `apps/agno-service/uv.lock` 锁定，无需 Docker、PostgreSQL 或 S3 即可运行本入口。根目录原有 `pnpm dev` 仍启动旧的5173工程，和本次5190产品相互独立。

## 模型配置

密钥只写在项目根目录 `.env`，不进入浏览器或源码：

```dotenv
AGNO_API_KEY=你的模型密钥
AGNO_BASE_URL=https://api.deepseek.com/v1
AGNO_MODEL=你的模型标识
```

未填写 AGNO_* 时自动兼容已有 DSH_API_KEY、DSH_BASE_URL、DSH_MODEL。本机已使用现有 DeepSeek 配置进行真实工具调用验收。应用和数据存储在本地，模型通过已配置的网络接口调用，因此不是完全离线运行。

修改配置后执行停止、启动命令。密钥缺失、模型不可用或超时都会显示真实错误，不会切回固定回复。

## 架构与数据

运行链路：浏览器5190 → 同源 `/api/local` → 本地5191服务 → Agno模型与受控工具 → SQLite及本地文件。

- Agno负责多轮理解、工具选择、草稿字段填写、制度问答、规则建议和报告任务。
- 业务工具负责单据查询、金额统计、规则检查、版本管理和模拟业务受理。模型没有提交、批准或付款工具。
- 提单仍由用户在右侧抽屉检查、勾选确认后提交。服务器重新校验并生成唯一单号、持久化回执和查询记录；重复请求复用同一回执。
- 同一类单据目前共用一个当前草稿，提交后可“新建同类单据”；历史提交快照、单据、回执不会被新草稿替换。本版本面向本机单用户演示，不提供多用户身份隔离。
- 浏览器只缓存界面偏好和输入草稿；业务对象、会话、运行记录和文件元数据以服务器为准。运行事件支持重连，服务重启会将未完成任务明确标为暂停。
- 报销和差旅看板、对话图表及其报告共用本地合成台账。台账包含 2026 年 8 月 1 日至 11 月 22 日的 612 笔示例报销，每笔差旅报销关联一段已完成的行程。按费用发生日或行程出发日归入所选期间，员工排行使用差旅报销金额。工作台本机席位为财务部主管吴侠，默认查看财务部，另有销售部、研发部的统计权限。生产环境的身份和业务数据须由企业系统提供。公开财报沿用其披露来源。
- 「问小智」为当前看板单独建立会话，带入业务系统、部门和日期。常用统计直接读取服务端汇总，开放式问题由 Agno 调用分析工具。会话报告保存已查结果与数据来源，支持费用报销、差旅管理、公开财报和当前会话已汇总的费用 CSV，导出的 HTML 可离线阅读。
- 选择已上架技能后，Agno读取对应版本的指令和资源。技能支持文本及含 SKILL.md 的 ZIP：上传后进行结构和依赖检查，再人工审核/发布。脚本通过本机受限执行器运行，生成文件可保存、预览、下载；不直接使用宿主裸脚本执行。
- 定时预审为本地服务的真实调度：启用后按上海时区每日指定时间执行，重启不会重复执行当天已完成任务；通知只产生于实际预审结果。

数据目录默认为 `.runtime/agno-local/`：`workspace.sqlite3` 保存业务与运行记录，`files/` 保存原件，`api.log`、`web.log` 保存运行日志。可通过 AGNO_DATA_DIR 指定其他本地绝对路径。备份时先停止本地服务，再复制整个目录；不要直接删除数据库或只复制正在写入的主文件。

## 可直接走的路径

1. 在「数据分析」选择费用报销、财务部和 2026 年 9 月，查看 43 笔报销、82,812.90 元总额。在看板打开对话后询问“我部门谁出差费最多”，九月首位应为宋欣，6 次行程合计 20,796.10 元。
2. 在同一分析会话输入“生成报告”，打开报告并核对所选日期、部门和已查询的图表。也可直接从新会话询问“九月份我部门的费用和差旅情况怎么样”。
3. 输入“上海出差住宿每晚700元符合标准吗”，检索合成制度并展示来源卡片。
4. 输入“帮我填写差旅申请：11月19日从杭州乘高铁去上海拜访客户，11月21日高铁回杭州”，在抽屉核对信息、检查、确认提交，再查询本地回执和单据。
5. 在材料页上传文本、PDF或Word，下载原件并核对字节；在对话中引用可解析文件做摘要或翻译。
6. 在规则中心描述业务检查条件，经生成和语义校对形成草稿，核对后保存启用，再重新预审。规则详情或编辑页的“样例测试”可用合成业务数据调用同一执行器。修改规则会使旧检查失效。
7. 上传技能文件或 ZIP 包，查看包检查与依赖结果，保存、申请审核并录入审核结论；已发布可调用的版本可在会话中选择，也可由 Agent 检索并加载。

## 接入边界

OA、资金、发票查验及制度不是外部真实企业系统。界面显示“本地已受理”表示模拟业务服务已保存记录，不代表外部审批或支付成功。

真实上传文件会保存字节。文本、CSV、Markdown、JSON、YAML、文字型PDF及Word可提取内容；图片、扫描PDF没有接入OCR。Excel/PPTX等二进制原件可由已加载技能通过文档库处理；含 SKILL.md 的 ZIP 在技能上传检查时安全解包，不将任意ZIP当作可执行技能。2026-11-17按用户要求移除发票查验，报销流程为“提取→核对→填单→提交”；系统不提供或宣称验真结果。保留必填、金额、附件完整性、重复材料及提交幂等检查。合成材料不会冒充新文件识别结果。

通用技能的本机依赖、导入使用、可上传样例及运行限制见[通用技能本机运行说明](通用技能本机运行说明.md)。当前脚本执行适配 macOS，依赖可用的 sandbox-exec；其他系统须接入受控执行器后再启用脚本。Office 在线预览还需本机 LibreOffice，缺少时保留原件下载。

规则生成与校对均调用模型，支持当前单据事由、行程、活动和费用明细的语义条件及组合；执行时模型返回命中、未命中或证据不足及原文证据，代码核验规则编号、来源路径和引用。原有金额、天数、附件与重复检查保留确定性执行。外部黑名单、发票验真、跨单累计等缺少事实来源的需求仍明确拒绝。模型异常或输出无法核实时最多重试一次，随后显示待核实。个人语义规则只提醒，不升级为公司拦截；实际提交仍须用户确认且通过基础校验与公司强制检查。业务问数报告固定生成时的图表和范围，可以从原会话再次查看或下载 HTML。历史公开财报仍可在原会话中查看年报来源和指标明细。

## 材料核对与费用汇总（2026-11-17）

材料与文件页选择实际上传的文件后“提取费用”，或在对话引用文件要求提取。Agno从可读文本提取费用，并保留原文证据；金额、日期、用途等不明确时留空待补。打开材料卡逐项修改、保存确认，勾选本次核对后生成报销草稿，在右侧抽屉补全字段、检查并确认提交。不同文件选择范围相互隔离，不混入既有样例。重复提取保留已保存的人工修改。

“技能·工具→小工具→CSV费用汇总”使用实际上传CSV的“费用类型、金额”列（也接受category、amount）。按整数分计算合计与分类小计，支持负数冲减，拒绝无效金额。结果与原件保存在服务端，可刷新后查看或下载CSV。页面提供示例CSV；对话引用CSV并输入“调用费用汇总小工具汇总这个文件”会执行同一服务端工具。既有其他小工具保留原实现。

单个汇总文件上限2MiB、10000条费用，支持UTF-8及GB18030。材料提取每次最多10个文件，不能解析的材料可在报销单中手工填写。本轮未启用长期记忆、Team、Workflow或其他Agno高级能力。

新增API：`POST /api/local/materials/extract`、`POST /api/local/tools/expense-summary`、`GET /api/local/tools/results`及结果详情/下载接口。旧工作空间启动时会迁移移除发票查验规则，保留已有回执和历史提交快照。修改前源码及SQLite一致性备份见 `artifacts/flow-simple-20261117/`。
