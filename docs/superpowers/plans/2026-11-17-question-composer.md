# 输入区追问实施记录

用户已从三个可点击方案中选择“输入区追问”，授权按该方向优化。沿用现有企业主题、服务端问题协议及差旅业务规则。

## 选定交互

问题标题、必要背景及选项位于底部输入区域上方；同一区域提供文字回答和“发送回答”。单选、多选与文字补充均保留，不预选、不点击即提交。用户可“稍后回答”，回答完成后恢复普通输入框及原先未发送的消息。问答草稿单独按会话和问题保存，切换、刷新及失败不串答、不丢内容。聊天记录保留简洁待答状态，已答、暂缓、失效问题可展开查看；不在消息和输入区重复放两套交互表单。

完整单据编辑和提交继续在右侧抽屉完成；追问结束后才展示差旅卡片。推荐值不追问、同日到达默认、未定回程占位与明确修改规则不变。
