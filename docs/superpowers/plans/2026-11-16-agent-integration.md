# 财小智统一工作空间实施计划

**目标：** 在本地形成共享任务与对象状态的财小智前端，整合全部五个设计分析的最新版本，支持统一助手与集中处理台两种空间组织。

**架构：** 独立 React/Vite 入口，不更改现有业务系统。公共工作空间保存任务、对象引用和各应用状态；卡片进入唯一详情容器。全部流程在浏览器本地完成，不调用真实模型或业务提交接口。

**技术：** 已安装 React 19、TypeScript、Vite、Playwright。无新增依赖。

**依据：** 项目 AGENTS.md、全部8条项目对话清单、5个设计分析完整原始记录，以及本轮实际打开的最新本地页面。记录位于 artifacts/agent-integration-20261116/research。

## 统一约束

- 全中文界面；页头无用途副标题；使用指引默认隐藏于角落。
- 不显示演示标签，不以固定回复假冒真实后台；提交缺少业务回执时显示待回执。
- 卡片紧凑、摘要不超过两项；复杂表单与证据进入单层详情。
- 最新统计：集团10月48.60万，销售部21.80万，销售部9月19万。
- Logo保留蓝白机器人识别；不沿用旧绿色demo视觉。
- 不修改已有各应用，不停止已运行服务，不发布云端。

## 重点验证

1. OA无金额、付款不沿用审批预估；部分来源失败不能显示零条。
2. 修改有效规则后相同范围预审失效；草稿变化必须重新检查。
3. 技能引用不等于执行，可见/下载/调用权限分开。
4. 分析组织范围跨对话、明细与导出一致。
5. 未取得回执不显示提交成功；刷新/切换保留草稿。
