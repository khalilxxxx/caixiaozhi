# 差旅追问与默认行程优化

用户已明确本轮规则并授权持续优化：已有自动推荐不追问，仅追问无法补齐的行程信息；到达日期默认等于该段出发日期；返程未定可生成待补回程，后续依据明确回答更新。沿用已有追问卡、独立草稿和右侧编辑抽屉。

## 实施与验收

- [x] 默认规则：所有差旅申请行程在出发日期有效且到达日期未明确时采用同日；明确到达日期、明确跨日和人工清空优先，报销不根据计划补事实。
- [x] 待补回程：用明确的返程未定状态生成一次回程段，城市衔接实际行程、交通使用现有推荐，日期保持空；后续明确日期更新原段，不重复建段，不改变其他人工信息。明确单程不自动增加回程。
- [x] 追问策略：可靠默认直接使用，缺失目的地、出发日期等才追问；已明确暂未确定的信息不重复问。新旧单歧义仍先厘清，不擅自覆盖旧单。
- [x] 卡片时机：草稿及业务引用持续保存；追问期间不展示差旅结果卡，回答完成后才呈现可编辑卡片。失败与刷新保持已保存成果与上下文。
- [x] 用先失败后通过的行为测试验证默认日期、回程占位、明确修改、追问与卡片先后；完成类型检查、构建、相关回归、隔离真实模型和浏览器验证。

不改变正式提交要求；待补回程可保存草稿，缺失日期仍由提交校验提示。保留其他工作区改动，不自动提交或推送。
