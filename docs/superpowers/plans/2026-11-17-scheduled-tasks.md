# 我的工作与定时任务实现计划

本轮由当前会话直接实施，沿用现有React、FastAPI、SQLite和Agno，不新增菜单入口、不部署。

## 目标与设计

将#todos的产品名称统一为“我的工作”。新增#schedules管理页：搜索与状态筛选、创建、修改、启停、删除、立即运行、历史结果。完整任务配置使用居中弹窗；运行记录在页面内展开。任务支持整理待办预审与自定义Agent指令，时间固定北京时间，频率为每天、周一至周五、每周选定日期、单次。

服务端持久化配置及执行记录，不依赖网页计时。旧每日预审迁移一次，旧设置入口接入同一管理页。到期事务认领、同一任务不重入；服务中断不自动重复执行，超过15分钟的错过执行记为未执行并推进下一次。启用或改时间后从下一次未来时刻起执行。单次任务执行后关闭，手动运行不改变原计划。失败记录保留原因，自定义任务缺模型配置时明确失败。定时任务不能自动回答需用户确认的问题，遇到提问标记为待确认。

## 实施步骤

- [x] `tests/test_scheduled_tasks.py`：先验证重复认领、并发、时间边界、单次/工作日/每周、修改冲突、删除与重启、失败及迁移。
- [x] `scheduled_tasks.py`：独立SQLite表、校验和时间计算、版本化CRUD、事务认领、运行完成/中断与Agent结果同步。
- [x] `scheduled_task_routes.py`与`server.py`：注册接口，后台调度接入，复用现有业务和Runtime，关停清理。
- [x] `ScheduledTasks.tsx`及`schedules.css`：真实管理页和居中编辑弹窗，错误、空态、运行历史、键盘与未保存保护。
- [x] `App.tsx`、`workspace.tsx`、`Supporting.tsx`和`RulesSubmission.tsx`：重命名、隐藏路由、旧设置统一入口及会话结果访问。
- [x] 使用临时SQLite运行后端测试和浏览器验收；类型检查、生产构建，验证现有首页与预审不回归。

## 验收重点

- 浏览器刷新/关闭不丢配置；无重复执行或假成功。
- 运行中不重入；编辑删除不破坏已发生历史，版本冲突可恢复。
- 北京时间午夜、周末、跨周、过去的单次时间得到正确处理。
- 未配置模型、服务不可达、任务抛错、需用户回答均显示真实状态。
- 不创建任何用户未要求的真实定时任务；验收数据只写临时数据库。

## 验收结果

2026-11-17：15项后端测试通过；TypeScript检查及Vite构建通过。独立临时数据库的浏览器验收覆盖我的工作更名、隐藏路由、旧设置入口、创建、持久化、启停、每周编辑、搜索、删除、真实待办预审及查看结果会话，并检查1440px/1280px桌面布局。

当前本地服务5191已在确认无执行中会话后重启，迁移前使用SQLite备份保留数据。正式数据库只迁移1个原有暂停任务，未新增或启用验收任务。临时测试服务验收结束后停止。

补充决定：沿用现有服务4任务并发上限，容量满时手动请求返回可重试状态，定时任务等待下一轮检查。错过窗口超过15分钟如实记为未执行。
