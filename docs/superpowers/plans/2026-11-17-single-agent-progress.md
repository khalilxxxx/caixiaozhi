# 单 Agent 执行进度实施计划

目标：开启 thinking，交付真实执行过程、可核验成果与工具衔接。
依据：../specs/2026-11-17-single-agent-progress-design.md。用户已授权开始；沿用当前工作区全部已有改动，在 codex 分支实施。

## 约束

中文产品文案；灰白与珊瑚色沿用既有界面；提单留在右侧抽屉；使用指引默认收起；不展示隐藏思维；不增加长期记忆、多Agent或自动业务提交。修改前快照在 artifacts/single-agent-progress-20261117/before.tar.gz。

## 任务

- [x] 后端：thinking与稳定步骤标识、持久执行记录、完成/失败/暂停判定。先添加状态迁移测试并确认失败，再实现、回归。
- [x] 前端：步骤事件归并、流与历史消息合并、可展开进度和继续交互。先验证去重/重试/终态等逻辑，再接UI。
- [x] 工具：成果格式核验、OCR复用、业务结果快照导入，测试数据来源与已核对结果保护。
- [x] 验收：聚合回归、类型/构建、独立代码复核，真实模型工具调用，桌面/窄屏交互与截图，记录实际边界。

## 重点验证

同名工具多次调用不合并；重连不重复；文本增量不清空步骤；失败不伪装全部成功；取消/重启后无永久运行标记；追问保留草稿；缺成果不能标为已交付；输入与用户向上滚动不被抢占。
