# Agent 追问交互实施计划

> 执行技能：superpowers:executing-plans；独立部分并行，集成后统一复核。

**目标：** 提供可回答并继续任务的追问卡片，保护现有草稿。
**架构：** 服务端持久化问题与答案；前端在消息中渲染问题并通过原运行入口回答；草稿用独立实例保存。
**技术栈：** React / TypeScript / FastAPI / Agno / SQLite。
**设计：** `docs/superpowers/specs/2026-11-17-agent-clarification-design.md`。

## 约束

- 中文产品文案；现有企业主题；完整填单与确认提交在右侧抽屉。
- 保留工作区已有未提交改动，不自动提交混合工作。
- 不引入 Agno 高级编排；沿用普通工具和后续轮次，问题等待期间不保持模型请求。

## 重点验证

- 旧卡片、重复回答不能再次执行；回答不跨会话。
- 自由输入能带回上下文，不能默认授权改写原单或提交。
- 刷新与服务重启保留待回答问题，失败后可以恢复。
- 新草稿不继承示例数据，原草稿和编辑保留。
- 对话旁打开抽屉时，答案仍绑定原问题的任务与草稿。
