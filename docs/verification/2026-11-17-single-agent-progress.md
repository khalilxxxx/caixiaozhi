- 业务工具结果直接形成带来源的只读快照供技能使用；图片和扫描 PDF 复用 OCR，保留页码、证据与人工核对结果。

## 实际边界

- 本轮没有加入多 Agent 或长期记忆；输入缓存只用于刷新保护。
- 简单问题仍可能只需要一次工具调用，步骤数量取决于实际任务，不人为拆步骤。
- 金额核验只证明指定明细列合计与来源一致，不代表逐笔业务正确；未做业务核验的成果仍明确标为未核验。结构检查不等于视觉版面验收，尚未提供通用版面智能检查。
- 文件完成检查针对明确创建句中的数量和格式，不是对任意自然语言复杂项目的全面验收。
- OCR 仍依赖本机 macOS Vision 能力；业务数据仍来自当前本地模拟数据源。
- 构建存在单个包超过 500 kB 的提示；后端存在既有 Starlette/httpx 弃用提示，均不影响本轮检查通过。
